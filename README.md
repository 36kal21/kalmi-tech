# KalMi Tech — Company Website

A company website showcasing digital services and company information.

## Live Website

https://kalmitech.netlify.app/

## About the Project

KalMi Tech is a company website project built to present digital services and provide information about the business.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Netlify for deployment

## Features

- Company introduction
- Digital services section
- English and Amharic content
- Website navigation
- Contact form interface

## Project Structure

- `index.html` — website structure
- `styles.css` — website styling
- `script.js` — JavaScript functionality
- `assets/` — project images and resources

## What I Learned

- Building web pages with HTML
- Styling layouts with CSS
- Adding interactivity with JavaScript
- Organizing project files
- Deploying a website with Netlify
